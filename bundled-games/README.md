# bundled-games/ (generated)

This directory is generated by `node tools/fetch-games.mjs` — do not edit by hand.

Each subfolder is one game: the original game file(s) (verbatim, unmodified), a generated `playhub.manifest.json`, and a `thumb.*` image when the source provided one.

Per-collection license texts live next to the folders (`*-LICENSE.txt`) and are referenced from each manifest. GPL-licensed games ship with their full license text and attribution.
